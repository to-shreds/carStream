CARSTREAM · TRY STREMIO

Your phone, in Stremio.

Keep this tablet on CarStream Wi-Fi, even when Android says it has no Internet. Keep CarStream running on your phone.

Checking the phone…

  1. Tap Copy add-on address below.
  2. Open the Stremio Android app. In Add-ons, use the option to add an add-on by URL. Paste the full address and install CarStream on your phone.
  3. Open CarStream Shows or CarStream Movies in Stremio's catalogs. Pick a download, then an episode.

Keep http:// at the start of the address. This is a private local connection. The phone fetches the video using mobile data; the tablet receives it over CarStream Wi-Fi.

Having trouble?

Install and open Stremio while connected to home Wi-Fi first. Finish any sign-in there, then reconnect to CarStream Wi-Fi.

If Stremio refuses the HTTP address, cannot install without Internet, or stays on its loading screen, this test has found a Stremio compatibility limit. Take a screenshot of the message and use Watch QR on the phone to return to Chrome.

If the list is empty, refresh Library on the phone. Only videos marked ready appear. If the phone's Wi-Fi address changes or you reset the pairing code, remove the old CarStream add-on and install it again using this page.

Use Stremio's playback controls. CarStream's browser remote controls, parent lock, Smart Skip and browser watch progress do not control Stremio. Automatic next depends on Stremio's settings.

Keep the add-on address private. A signed-in Stremio account may sync it to your other devices. It contains a local access token, never your TorBox API key.
