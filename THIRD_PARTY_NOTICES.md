# Third-party notices

## LibVLC Java API compatibility classes

CarStream retains the small unmodified LibVLC Java API JAR solely because legacy, unreachable phone-player methods remain in the source. This release does not contain `libvlc.so`, `libc++_shared.so`, or any other native VLC runtime. LibVLC is part of the VideoLAN project and is available under the GNU Lesser General Public License, version 2.1 or later.

## hls.js 1.7.0

CarStream downloads and caches the pinned hls.js light browser bundle so Chrome can play HLS while connected to a local-only Wi-Fi network. hls.js is available under the Apache License 2.0.
