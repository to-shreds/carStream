TorBox Web PlayerSECURE SETUP

ONE-TIME SETUP

Your key stays in Render.

This page creates a salted password hash in your own browser. It does not send the password anywhere or change your server settings.

1. Choose your household password

Keep this hash out of GitHub too. You will sign in with your chosen password, not with the hash.

2. Add two values in Render

Open the torbox-web-player service in your Render dashboard, then open Environment and choose Edit.

HOUSEHOLD_PASSWORD_HASH
Paste the hash created above.
TORBOX_API_KEY
Paste your TorBox API key directly into Render. Do not paste it on this page, into a chat, or into a repository file.

Choose Save, rebuild, and deploy (or the equivalent save-and-deploy action shown in Render). After the deployment is live, return here.

Open Render dashboard

3. Open the player

Sign in, choose a library file, and test playback. Start with a browser-compatible MP4. Test sound, seeking, and resuming after reloading before relying on this preview.

Open player
The preview uses temporary server memory, not a database. Progress and device sessions reset when the server restarts. This setup page does not grant access to the household: only configuration through your Render account can set the password.
